# 反代集合

Windows 10/11 64位本地 AI 反代服务一键安装包。账号和密钥由使用者在目标电脑自行填写。

## 下载与安装

进入 [Release 下载页](https://github.com/1021691705-rgb/fandai-jihe/releases/tag/v2026.10.24)，下载 `AIProxySuite-Setup-20261024.exe`。

1. 把安装包复制到目标电脑，双击运行，点击“开始一键安装”。
2. 首次保持联网，预留约 4 GB 磁盘空间，无需手动安装 Python 或 Node。
3. 安装完成后打开桌面的“AI 反代服务控制台”，配置自己的账号、密钥及代理，再启动所需项目。

安装包约 360 MiB。`SHA256SUMS.txt` 用于核对下载完整性。

## 包含项目

| 项目 | 说明 |
| --- | --- |
| ChatGPT2API | 本地服务与预构建前端 |
| Antigravity Tools | 桌面程序，需自行登录和配置 |
| Flow2API | 独立运行环境与服务 |
| Gemini Web Bridge | 网页桥接服务 |
| LocalQwenPS | 本地桥接与现有 Photoshop 插件代码 |
| 智绘引擎 | 桌面程序、现有插件及自定义 API 运行时 |
| LocalQwenPSCloud | 云版桥接及 0.10.6 Photoshop 插件 |

此仓库交付上述七组已确认项目的迁移安装包，不代表电脑上所有未知项目。未包含代理订阅、Ollama 模型、DXOS 主画布或注册机。

## 数据与安全边界

- 未携带原电脑的账号、Cookie、密钥配置、账号数据库和任务日志；目标电脑本地管理密钥在安装时新生成。
- 填写账号后的安装目录可能包含个人数据，请勿再次直接上传或转发。
- 安装器没有商业数字签名；请按正常的信任审核流程处理提示，不要关闭防护。
- 不默认创建开机自启，不自动注册账号或生成图片。
- Photoshop 需要自行正常安装并授权；Adobe 可能要求通过 UXP Developer Tools 正常加载插件一次。
- 第三方软件的账号授权、许可和使用条款仍需遵守；本仓库不对第三方软件重新授予许可。
